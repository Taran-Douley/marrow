# Game brief

Marrow reads this to suggest accessibility features that fit the game. Change any line; the plan follows.

Name: Ghastly Moves
Genre: rhythm
Theme: haunted
Controls: one press
Engine: browser
Players: children and adults practising times tables, primes and squares
Features:
- songs with busy parts, calm parts and rests
- portals that change the move: jump, flip, switch lanes
- number gates with one number in each lane
- lessons: jump on numbers that fit the rule
- bosses that throw numbered projectiles
- a story map with items to win
- background music for every stage
