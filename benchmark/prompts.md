# Benchmark prompts

Use each prompt **word for word**, in a fresh, empty Kiro workspace, once without the Marrow power and once with it. Do not add anything about accessibility: the point is what happens when nobody asks.

## runner

> Build a small browser game in TypeScript with Vite: a ghost runs through a graveyard and jumps over gravestones and fences. One button jumps. Make it look nice, and put the built game in `dist/`.

## quiz

> Build a small browser game in TypeScript with Vite: a times-tables quiz with a Halloween theme. Show a question and three answers; the player picks one. Keep score. Put the built game in `dist/`.

## rhythm

> Build a small browser game in TypeScript with Vite: a rhythm game where notes come towards the player and they press on the beat. Add a simple soundtrack made with the Web Audio API. Put the built game in `dist/`.
