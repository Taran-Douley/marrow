# Accessibility features: Séance Escape

Séance Escape supports these ESA Accessible Games Initiative tags: Mono Sound, Stereo Sound, Surround Sound, Narrated Menus, Playable without Button Holds, Playable without Rapid Button Presses, Playable with Keyboard Only, Playable without Motion Controls, Playable without Touch Controls. It provides, but a person must confirm against the tag’s criteria: Multiple Volume Controls, Playable with Mouse Only, Playable with Touch Only, Clear Text, Large Text, Large & Clear Subtitles, Color Alternatives, Camera Comfort. This lists supported features. It is not a claim that the game is accessible to everyone, and it does not replace testing with disabled players.

## Supported

The kit guarantees these, and the proof properties behind them pass.

| Tag | Why |
|---|---|
| Mono Sound | A mono option centres every sound. |
| Stereo Sound | Placed sounds are panned left and right, and made quieter and duller with distance. |
| Surround Sound | Cues carry a direction all the way round, ahead and behind included, played with a 3D head-related panner where the browser has one. |
| Narrated Menus | Menus and options are spoken, and every spoken line is also written to a live text region for screen readers. The voice can be turned off to avoid double speech. |
| Playable without Button Holds | Key repeat is ignored and no hold is ever needed; the house proof, ritual included (201 to 206) passes, so it can be finished with one switch. |
| Playable without Rapid Button Presses | One press at a time with time between, and nothing to mash; the house proof, ritual included (201 to 206) passes, so it can be finished with one switch. |
| Playable with Keyboard Only | Any key is the switch, and the menus are ordinary controls; the house proof, ritual included (201 to 206) passes, so it can be finished with one switch. |
| Playable without Motion Controls | The game uses no motion controls. |
| Playable without Touch Controls | It can be played with the keyboard, so touch is not needed; the house proof, ritual included (201 to 206) passes, so it can be finished with one switch. |

## Provided, to confirm

The feature exists. The tag has criteria a person must check.

| Tag | Why |
|---|---|
| Multiple Volume Controls | Separate volumes exist for beeps and effects, for speech and for music. Wind and room tone share the music volume, so confirm that meets the tag’s separate ambient control. |
| Playable with Mouse Only | A click anywhere is the switch, but Escape (back to the menu) is a key. Confirm the whole game can be played with the mouse alone. |
| Playable with Touch Only | A tap anywhere is the switch, but Escape (back to the menu) is a key. Confirm the whole game can be played by touch alone. |
| Clear Text | The font is Atkinson Hyperlegible with sans-serif fallbacks, and the themes meet 4.5:1 contrast. Confirm the default text height meets the tag (26 px at 1080p). |
| Large Text | A text size setting scales the text. Confirm it reaches the size the tag asks for. |
| Large & Clear Subtitles | Every spoken line is also written as a caption, with a size setting. The tag covers spoken dialogue and asks for an adjustable background and no overlap with the game; confirm both. |
| Color Alternatives | Information is carried by words and shapes as well as colour, and there is a colour-blind palette. Confirm no meaning rests on colour alone. |
| Camera Comfort | The view has a moving camera. A reduced-motion setting cuts the glide and the head bob. Confirm it meets the tag. |

## Not claimed

Not built, not applicable, or a proof is failing.

| Tag | Why |
|---|---|
| Difficulty Levels | Speed changes the timing only. The tag asks for changes such as enemy health, damage or lives, which this kit does not offer. |
| Save Anytime | Not claimed. Progress is saved at the end of a stage, not at any moment. |
| Basic Input Remapping | Any key, click, tap or gamepad button is the switch, so there is nothing to remap. The tag asks for a remapping option, so it is not claimed. |
| Full Input Remapping | Not claimed, for the same reason as basic remapping. |
| Stick Inversion | Does not apply: there are no sticks to invert. |
| Playable with Buttons Only | A gamepad button works as the switch during play, but the settings menus need a pointer or keyboard, so it is not claimed. |
| Chat Speech-to-Text & Text-to-Speech | Does not apply: there is no chat. |
