# Kiroween 2026 rules (reference with #kiroween-rules)

Source: https://kiroween.devpost.com/rules (read 3 Nov 2026).

## Dates
- Submission period: 30 Oct 2026 9:00am PT to **4 Dec 2026 2:00pm PT (10:00pm UK)**. No extensions.
- Kiro credits: request 4,000 by 1 Dec 2026 12:00pm PT; redeem by 4 Dec; they expire 31 Dec.
- Judging: 16 Dec 2026 to 29 Jan 2027. Winners around 3 Feb 2027.

## Eligibility
- New projects only, built during the submission period, using Kiro (IDE, CLI, Web and/or Crew). Insufficient Kiro use can disqualify.
- Standard frameworks, libraries and starter templates are allowed. **Any other pre-existing code or work must be disclosed.** (Disclose that a throwaway browser prototype, made outside Kiro after 30 Oct, was used for early player testing; none of its code is in this repository.)
- Teams up to 3. This entry is solo.

## Submission requirements
- Category: **Skeleton Crew** (lean template plus two distinct apps in two separate folders).
- Public GitHub repository with all code, assets and instructions; an open-source licence visible in the About section.
- `/.kiro` at the repository root, never gitignored.
- URL to the working apps; test credentials (none needed) in the private field.
- Text description of features.
- Demo video under 3 minutes, public on YouTube, showing the project working; no third-party trademarks or copyrighted music.
- Write-up on how Kiro was used: IDE/CLI/Web/Crew, custom agents, hooks, spec-driven development, steering, MCP, property-based testing, powers.

## Judging
- Stage one (pass/fail): fits the theme and reasonably uses Kiro.
- Stage two, five criteria at 20% each:
  1. **Potential Impact:** real problem, real audience, would someone use it.
  2. **Technological Implementation:** how thoroughly and skilfully Kiro is used; variety, depth, experimentation.
  3. **Design:** a complete, coherent product, not a technical proof of concept.
  4. **Innovation/Idea:** novel and different from existing concepts.
  5. **Presentation:** the video shows it working end to end; problem, audience and why it matters are clear; memorable.
- Judges are not required to run the project and may judge from the video, text and images. Judging may include AI-driven analysis.

## Prizes
- Overall: 1st $30,000, 2nd $20,000, 3rd $10,000. Category: $5,000 each. A project wins **one Overall or one Category prize**, plus any number of bonuses.
- Bonuses: Best Startup Project $10,000 (founder confirmation, LinkedIn, startup website); Best Ghost of Kiroween Past $2,000 (registered for Kiroween 2025); Best Kiro Crew App $1,000 (separate public Crew app repo, chosen from the top 50 by the Kiro team); Best Student Project $1,500 per category; **Best Demo $1,000 (highest Presentation score among the top 10% overall)**; Bonus Blog (2,000 credits, top 100 with a qualifying post); Social Blitz (post must start with #KiroweenHackathon26).

## Pass/fail checklist
- [ ] Registered on Devpost; credits requested
- [ ] Public GitHub repo with MIT licence visible in About
- [ ] `/.kiro` at root, not ignored
- [ ] Two app folders (apps/ghastly-moves, and the second game's folder)
- [ ] Crew app in its own public repo (same account) if entering that bonus
- [ ] Disclosure of the prototype in the submission text
- [ ] Working URLs
- [ ] Video under 3 minutes, YouTube, public
- [ ] Kiro usage write-up covering every feature used
- [ ] Startup fields, if entering Best Startup
- [ ] Blog post and social post published during the submission period
- [ ] Submitted by Thu 3 Dec (a day early)
